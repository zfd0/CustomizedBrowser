# 术语表

## 项目术语统一规范

本文档定义了 Customized Browser 项目中使用的统一术语，所有开发者必须严格遵循。

---

## 核心术语

### 1. 实例 (Instance)
- **定义**：一个独立的浏览器运行环境，拥有独立的数据目录、缓存、Cookie 等
- **使用场景**：
  - 多账户登录隔离
  - 工作/个人浏览分离
  - 不同用途的数据隔离
- **相关文件**：
  - `Models/InstanceInfo.cs` - 实例信息模型
  - `Services/IInstanceService.cs` - 实例服务接口
- **注意**：不要使用"浏览器窗口"、"Profile"等术语，统一使用"实例"

### 2. 实例 ID (InstanceId)
- **定义**：实例的唯一标识符，同时也是实例的名称
- **数据类型**：`string`
- **格式**：推荐使用 `Instance_yyyyMMdd_HHmmss` 格式
- **注意**：InstanceId 具有唯一性，不能重复

### 3. 会话 (Session)
- **定义**：一个实例的运行状态，包括打开的标签页、URL、滚动位置等
- **使用场景**：
  - 启动时恢复上次的浏览状态
  - 保存当前的工作进度
- **相关文件**：
  - `Models/SessionState.cs` - 会话状态模型
  - `Services/ISessionService.cs` - 会话服务接口

### 4. 标签页 (Tab)
- **定义**：浏览器中的单个浏览页面
- **相关文件**：
  - `Models/TabState.cs` - 标签页状态模型
- **注意**：不要使用"选项卡"，统一使用"标签页"
- **标签页状态相关术语**：
  - **活动标签页** (Active Tab)：当前显示的标签页
  - **标签页标题** (Tab Title)：标签页上显示的页面标题
  - **标签页加载** (Tab Loading)：标签页初始化和页面加载的过程

### 5. 设置 (Settings)
- **定义**：浏览器的全局配置项
- **分类**：
  - 通用设置
  - 通知设置
  - 同步设置
  - 安全设置
- **相关文件**：
  - `Models/BrowserSettings.cs` - 设置模型
  - `Services/ISettingsService.cs` - 设置服务接口
- **注意**：不要使用"配置"、"选项"，统一使用"设置"

### 6. 实例包 (Instance Package)
- **定义**：将实例的标签页会话、备注与 Cookie（登录状态）打包而成的可迁移文件
- **文件扩展名**：`.cbx`（本质为 zip 压缩包）
- **包含内容**：`manifest.json`、`cookies.json`、`session_state.json`、`LastPage.json`、`note.txt`、`storage/`
- **使用场景**：将实例连同登录状态迁移到其他电脑
- **相关文件**：
  - `Models/InstancePackage.cs` - 实例包模型
  - `Services/IInstancePackageService.cs` - 实例包服务接口
- **注意**：`cookies.json` 为明文，等同于账号凭据，需妥善保管

## 浏览器核心术语

### 7. WebView2
- **定义**：微软提供的基于 Chromium 的现代 Web 浏览器控件
- **作用**：提供网页渲染、JavaScript 执行、Cookie 管理等核心浏览器功能
- **相关文件**：
  - `Services/IWebViewService.cs` - WebView 服务接口
  - `Views/BrowserWindow.xaml.cs` - 浏览器窗口实现

### 8. 地址栏 (Address Bar)
- **定义**：输入和显示当前页面 URL 的文本框
- **相关功能**：
  - 输入网址并导航
  - 显示当前页面的完整 URL
- **注意**：不要使用"URL 栏"，统一使用"地址栏"

### 9. 导航 (Navigation)
- **定义**：在网页之间跳转的行为
- **相关术语**：
  - **后退** (Back)：返回到上一个页面
  - **前进** (Forward)：前进到下一个页面
  - **刷新** (Reload)：重新加载当前页面
  - **主页** (Home)：导航到默认主页
  - **导航开始** (Navigation Starting)：开始加载新页面
  - **导航完成** (Navigation Completed)：页面加载完成

### 10. 页面标题 (Page Title)
- **定义**：网页的 `<title>` 标签内容，显示在标签页和窗口标题栏
- **相关事件**：`DocumentTitleChanged` - 页面标题变化时触发

### 11. 开发者工具 (DevTools)
- **定义**：用于调试网页的内置工具
- **功能**：查看 DOM、调试 JavaScript、检查网络请求等
- **快捷键**：F12

### 12. Cookie
- **定义**：网站存储在浏览器中的数据片段，通常用于保存登录状态、会话标识等
- **存储位置**：实例的数据目录（WebView2 用户数据文件夹）内
- **相关服务**：`IInstancePackageService`（导出/导入实例包时搬运 Cookie）、`ISiteDataService`（按网站读写 Cookie）
- **注意**：Cookie 由 Chromium 加密，密钥受 Windows DPAPI（机器 + 用户绑定）保护，
  直接复制实例目录会导致登录状态失效；跨机迁移需通过实例包导出/导入

### 13. 网站 (Site)
- **定义**：登录状态数据的管理单位，由 Cookie 域与站点存储来源共同构成，支持父子域双向匹配
  （例如 Cookie 域 `.deepseek.com` 与网站 `chat.deepseek.com` 视为同一网站）
- **使用场景**：提取网站、合并实例时以「网站」为单位组织 Cookie 与站点存储
- **相关文件**：
  - `Models/SiteTransfer.cs` - 网站条目与合并冲突模型
  - `Services/ISiteTransferService.cs` - 网站迁移服务接口
- **注意**：界面与文档中统一使用"网站"，不要使用"站点"（"站点存储"作为固定术语除外）

### 14. 站点存储 (Site Storage)
- **定义**：网站保存在浏览器中、Cookie 之外的登录相关数据，包括 IndexedDB、WebStorage、
  Local Storage、Session Storage
- **说明**：
  - IndexedDB / WebStorage 按来源（origin）分目录存放，可按网站整体复制
  - Local Storage 是整个配置文件共享的单体库（`Local Storage\leveldb`），无法按网站复制目录，
    需通过隐藏窗口访问站点后用脚本读写

### 15. 来源 (Origin)
- **定义**：站点存储的归属地址，由协议 + 主机名 + 端口构成，例如 `https://chat.deepseek.com`
- **说明**：IndexedDB 目录名（如 `https_chat.deepseek.com_0.indexeddb.leveldb`）可直接解析出来源地址

## 状态术语

### 实例状态 (InstanceStatus)
| 枚举值 | 中文显示 | 说明 |
|--------|---------|------|
| `Stopped` | 已关闭 | 实例未运行 |
| `Running` | 运行中 | 实例正在运行且窗口可见 |
| `Background` | 后台运行 | 实例正在运行但窗口隐藏 |
| `Starting` | 启动中 | 实例正在启动 |
| `Stopping` | 停止中 | 实例正在停止 |

### 主题选项 (ThemeOption)
| 枚举值 | 中文显示 | 说明 |
|--------|---------|------|
| `Light` | 浅色 | 浅色主题 |
| `Dark` | 深色 | 深色主题 |
| `System` | 跟随系统 | 跟随系统主题设置 |

### 隐藏窗口选项 (HideWindowOption)
| 枚举值 | 中文显示 | 说明 |
|--------|---------|------|
| `Close` | 关闭 | 关闭窗口即退出程序 |
| `Ask` | 询问 | 关闭窗口时询问用户 |
| `KeepRunning` | 后台运行 | 关闭窗口时保持后台运行 |

## 架构术语

### 服务 (Service)
- **定义**：负责特定业务逻辑的独立组件，提供接口供其他层调用
- **命名规范**：
  - 接口：`I{功能}Service`
  - 实现：`{功能}Service`
- **示例**：
  - `ISettingsService` / `SettingsService`
  - `IInstanceService` / `InstanceService`
  - `ISessionService` / `SessionService`
  - `ITrayIconService` / `TrayIconService`
  - `IWebViewService` / `WebViewService`
  - `IInstancePackageService` / `InstancePackageService`
  - `ISiteDataService` / `SiteDataService`
  - `ISiteTransferService` / `SiteTransferService`
  - `IBrowserWindowFactory` / `BrowserWindowFactory`

### 视图模型 (ViewModel)
- **定义**：MVVM 模式中的视图模型层，负责视图的业务逻辑和数据绑定
- **命名规范**：`{视图名}ViewModel`
- **示例**：
  - `MainViewModel`
  - `InstanceManagerViewModel`
  - `SettingsViewModel`

### 视图 (View)
- **定义**：MVVM 模式中的视图层，负责用户界面展示
- **命名规范**：`{功能名}Window` 或 `{功能名}Control`
- **示例**：
  - `MainWindow`
  - `InstanceManagerWindow`
  - `ExtractSiteWindow`
  - `MergeInstancesWindow`
  - `SettingsWindow`
  - `BrowserWindow`

### 工厂 (Factory)
- **定义**：负责创建对象实例的设计模式
- **相关接口**：`IBrowserWindowFactory` - 浏览器窗口工厂

## 目录术语

### 数据根目录 (Data Root Path)
- **定义**：应用程序存储所有数据的根目录
- **默认位置**：`%LocalAppData%\SimpleBrowser` (历史兼容性)
- **相关常量**：`AppConstants.GetDataRootPath()`

### 实例目录 (Instance Directory)
- **定义**：单个实例的数据存储目录
- **默认位置**：`{数据根目录}\Instances\{InstanceId}`
- **相关常量**：`AppConstants.GetInstanceDataPath(instanceId)`

### 用户数据文件夹 (User Data Folder)
- **定义**：WebView2 存储用户数据的目录
- **位置**：与实例目录相同
- **包含内容**：缓存、Cookie、本地存储等

## UI 术语

### 托盘 (Tray)
- **定义**：系统任务栏通知区域
- **相关服务**：`ITrayIconService`
- **注意**：不要使用"系统托盘"、"通知区域"，统一使用"托盘"

### 工具栏 (ToolBar)
- **定义**：窗口顶部的操作按钮区域
- **注意**：不要使用"工具条"，统一使用"工具栏"

### 状态栏 (StatusBar)
- **定义**：窗口底部的状态信息显示区域
- **注意**：不要使用"状态条"，统一使用"状态栏"

### 标签栏 (Tab Bar / TabControl)
- **定义**：显示所有标签页的区域
- **功能**：标签页切换、关闭、新建等

### 浏览器顶部区域 (Browser Top Area)
- **定义**：浏览器窗口顶部的功能区域，包含工具栏、地址栏和标签栏
- **组成部分**：
  - **工具栏**：导航按钮和操作按钮
  - **地址栏**：URL输入和显示
  - **标签栏**：标签页管理
- **作用**：提供浏览器的核心导航和操作功能
- **位置**：位于浏览器窗口的顶部，WebView2控件的上方

### 主窗口 (Main Window)
- **定义**：应用程序启动时显示的第一个窗口
- **功能**：显示实例列表、提供实例管理入口
- **UI元素**：
  - **工具栏**：包含新建实例、打开实例、实例管理、设置、锁定/解锁按钮
  - **实例列表**：显示所有实例的名称、备注、最后使用时间
  - **列表视图**：使用 GridView 展示实例信息，支持单击选择和双击打开

### 浏览器窗口 (Browser Window)
- **定义**：显示网页内容的窗口
- **功能**：网页浏览、标签页管理等
- **UI元素**：
  - **工具栏**：包含后退、前进、刷新、主页(实例管理)、停止按钮
  - **地址栏**：输入和显示当前页面URL的文本框
  - **标签栏**：显示所有标签页，支持标签页切换、关闭、新建
  - **WebView2 控件**：显示网页内容的核心控件
  - **标签页头部**：显示页面标题，包含关闭按钮

### 实例管理窗口 (Instance Manager Window)
- **定义**：用于管理所有实例的窗口
- **功能**：实例多选、批量操作、实例备注编辑、实例导出/导入、提取网站、合并实例等
- **UI元素**：
  - **工具栏**：包含新建实例、打开实例、停止实例、删除实例、导出实例、导入实例、提取网站、合并实例、设置按钮
  - **实例列表**：显示所有实例的名称、备注、最后使用时间
  - **列表视图**：使用 GridView 展示实例信息，支持鼠标框选多选、单击选择和双击打开
  - **右键菜单**：打开实例、停止实例、删除实例、导出实例、导入实例、提取网站到新实例、合并实例

### 框选 (Rubber-band Selection)
- **定义**：在实例列表上按住鼠标左键拖拽出选择矩形，矩形覆盖到的实例被批量选中的交互方式
- **相关文件**：`Views/InstanceManagerWindow.xaml.cs`
- **相关术语**：
  - **选择矩形** (Selection Rectangle)：框选时显示的半透明矩形
  - **追加框选**：按住 Ctrl 框选时在已有选中项基础上追加，而非重新选择

### 右键菜单 (Context Menu)
- **定义**：在实例上点击鼠标右键弹出的操作菜单，提供针对选中实例的常用操作
- **相关文件**：`Views/InstanceManagerWindow.xaml`
- **注意**：右键点击未选中的实例时，会先把该实例切换为选中项，再弹出菜单

### 提取网站对话框 (Extract Site Window)
- **定义**：用于把实例中指定网站的登录状态独立到新实例的对话框
- **UI元素**：
  - **网站列表**：显示检测到的网站（主机名、Cookie 条数、是否有站点存储），支持勾选
  - **全选/全不选/刷新按钮**：批量勾选与重新读取网站列表
  - **新实例名称**：新实例的名称输入框
  - **移除选项**：是否同时从源实例移除所选网站的数据
  - **提取/取消按钮**：执行提取或关闭对话框

### 合并实例对话框 (Merge Instances Window)
- **定义**：用于把多个实例的网站数据合并到目标实例的对话框
- **UI元素**：
  - **来源实例列表**：可勾选参与合并的实例
  - **目标实例**：合并结果写入的实例（可选择新建实例或已有实例）
  - **分析按钮**：预览各来源实例的网站与冲突情况
  - **冲突网站列表**：每个冲突网站通过下拉框选择保留哪个实例的数据
  - **合并/取消按钮**：执行合并或关闭对话框

### 设置窗口 (Settings Window)
- **定义**：用于编辑全局设置的窗口
- **UI元素**：
  - **设置选项卡**：不同类别的设置分组
  - **设置项**：具体的设置选项，如主题选择、默认主页等
  - **保存按钮**：保存设置更改
  - **取消按钮**：取消设置更改
  - **重置按钮**：重置设置为默认值

## 操作术语

### 启动 (Start)
- **定义**：使实例从停止状态变为运行状态
- **相关方法**：`IInstanceService.StartInstanceAsync()`

### 停止 (Stop)
- **定义**：使实例从运行状态变为停止状态
- **相关方法**：`IInstanceService.StopInstanceAsync()`

### 删除 (Delete)
- **定义**：永久删除实例及其所有数据
- **相关方法**：`IInstanceService.DeleteInstanceAsync()`
- **注意**：此操作不可逆！

### 导出 (Export)
- **定义**：将实例的标签页会话、备注与 Cookie（登录状态）打包为实例包
- **相关方法**：`IInstancePackageService.ExportAsync()`
- **注意**：导出前会先关闭该实例，以保存当前标签页并读取 Cookie

### 导入 (Import)
- **定义**：从实例包恢复实例（含登录状态）
- **相关方法**：`IInstancePackageService.ImportAsync()`
- **注意**：若同名实例已存在，可选择覆盖或以新名称导入

### 提取网站 (Extract Site)
- **定义**：把实例中指定网站的登录状态（Cookie + 站点存储）独立到新实例
- **相关方法**：`ISiteTransferService.ExtractAsync()`
- **注意**：处理过程中源实例会被停止；可选择同时从源实例移除所选网站的数据（不可恢复）

### 合并实例 (Merge Instances)
- **定义**：把多个实例的网站数据合并到目标实例
- **相关方法**：`ISiteTransferService.MergeAsync()`
- **注意**：处理过程中涉及的实例会被停止；目标实例中相同网站的旧登录状态会被覆盖；
  来源实例的数据保持不变

### 冲突网站 (Conflicting Site)
- **定义**：在合并时同时存在于多个来源实例中的网站，需由用户选择保留哪个实例的数据
- **相关方法**：`ISiteTransferService.PreviewMergeAsync()`

### 刷新 (Refresh)
- **定义**：重新加载数据或状态
- **相关方法**：`IInstanceService.RefreshInstanceStatuses()` (已移除)

### 锁定 (Lock)
- **定义**：锁定托盘菜单，防止误操作
- **相关方法**：`ITrayIconService.Lock()`

### 解锁 (Unlock)
- **定义**：解除托盘锁定
- **相关方法**：`ITrayIconService.Unlock()`

### 初始化 (Initialize)
- **定义**：设置组件或服务的初始状态
- **相关方法**：`InitializeBrowserAsync()`、`InitializeWebViewAsync()`

### 加载 (Load)
- **定义**：从存储中读取数据或状态
- **相关方法**：`LoadSessionStateAsync()`、`LoadInstances()`

### 保存 (Save)
- **定义**：将数据或状态写入存储
- **相关方法**：`SaveSessionState()`、`SaveProcessIds()`

### 激活 (Activate)
- **定义**：使窗口或标签页成为当前活动的
- **相关方法**：`Window.Activate()`

## Bug 报告术语

### 卡顿 (Lag / Stutter / Freeze)
- **定义**：应用程序响应变慢或暂时无响应
- **常见场景**：
  - 玩云游戏时帧率下降
  - 界面操作延迟
  - 页面滚动不流畅

### 崩溃 (Crash)
- **定义**：应用程序意外退出
- **相关术语**：
  - **未处理异常** (Unhandled Exception)：导致崩溃的错误
  - **错误日志** (Error Log)：记录崩溃信息的文件

### 加载失败 (Load Failed)
- **定义**：页面或资源未能成功加载
- **相关术语**：
  - **404 错误** (404 Error)：资源未找到
  - **网络错误** (Network Error)：网络连接问题
  - **超时** (Timeout)：加载时间过长

### 标题不更新 (Title Not Updating)
- **定义**：标签页或窗口标题未能正确显示当前页面标题
- **相关事件**：`DocumentTitleChanged`

### 标签页加载问题 (Tab Loading Issue)
- **定义**：标签页未能正确显示或加载
- **细分术语**：
  - **标签页未显示** (Tab Not Displayed)：标签页栏中缺少标签页
  - **标签页标题不正确** (Incorrect Tab Title)：标签页显示错误的标题
  - **标签页内容空白** (Blank Tab Content)：标签页内容区域为空
  - **标签页延迟加载** (Delayed Tab Loading)：标签页需要切换到可见状态才开始加载内容
  - **并行加载失败** (Parallel Loading Failed)：多个标签页未能同时加载

### 会话加载问题 (Session Loading Issue)
- **定义**：启动时未能正确恢复之前的浏览会话
- **细分术语**：
  - **会话恢复失败** (Session Recovery Failed)：完全无法恢复会话，显示默认页面
  - **部分会话恢复** (Partial Session Recovery)：只恢复了部分标签页
  - **URL 恢复错误** (URL Recovery Error)：恢复的URL不正确
  - **标签页顺序错误** (Tab Order Error)：恢复的标签页顺序与之前不同
